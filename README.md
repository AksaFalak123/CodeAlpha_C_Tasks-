# CodeAlpha C Programming Tasks

C Programming Internship tasks completed for CodeAlpha.

## Tasks Completed

### 1. Calculator in C - calculator.c
A console-based calculator that performs:
- Addition, Subtraction, Multiplication, Division
- Modulus and Power operations
- Menu-driven interface with loop

### 2. Matrix Operations - matrix.c
Performs operations on matrices:
- Addition and Subtraction of Matrices
- Multiplication of Matrices
- Transpose of Matrix

### 3. Banking System - bank.c
A simple Banking Management System:
- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- File handling to save account data

## How to Run

1. Compile any file using GCC:
   gcc calculator.c -o calculator
   gcc matrix.c -o matrix
   gcc bank.c -o bank

2. Run:
   ./calculator
   ./matrix
   ./bank

## Tech Used
- Language: C
- Compiler: GCC
- Platform: Windows
